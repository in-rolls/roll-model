02 / THE IDEA

A useful interface,
without the data risk.

The earlier project experimented with finding electoral-roll records by geography. This edition keeps the navigation and table workflow, rebuilt as a small, inspectable static site.

Records are generated in the browser from fixed rules. The names, IDs, regions, wards, and stations are all labelled examples. The CSV button exports only these generated records.
